---
title: Cannot Create New Document
description: Troubleshoot doc creation issues in S1Vo.
---

## Issue

- "Create Document" button is greyed out
- Nothing happens when you try to add a doc

## Steps to Fix

<Steps>
  <Step title="Check permissions">
    Ensure you have write access to the doc space. Ask your admin if unsure.
  </Step>
  <Step title="Refresh your browser">
    Reload S1Vo to clear session problems.
  </Step>
  <Step title="Clear cache">
    Log out, clear cache, then log back in.
  </Step>
</Steps>
