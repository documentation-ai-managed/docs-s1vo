## Overview

S1Vo provides a centralized hub for your project documentation. You create, organize, and collaborate on docs without the hassle of scattered files or complex tools. Build knowledge bases that scale with your team, featuring search, versioning, and seamless integrations.

<Callout kind="info">
S1Vo supports Markdown, rich embeds, and custom workflows to streamline your documentation process.
</Callout>

## Quick Start Guide

Get up and running in minutes:

<Steps>
  <Step title="Create Account" icon="user-plus">
    Visit `https://s1vo.com` and sign up with your email.
  </Step>
  <Step title="Set Up Workspace" icon="settings">
    Name your project space and invite team members.
  </Step>
  <Step title="Publish First Doc" icon="file-text">
    Write in Markdown and hit publish.
  </Step>
</Steps>

Here is a simple example to embed S1Vo docs in your app:

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  const s1vo = require('s1vo-sdk');
  
  async function embedDoc(docId) {
    const embed = await s1vo.embed(docId, {
      theme: 'light',
      apiKey: 'YOUR_API_KEY'
    });
    document.getElementById('doc-container').innerHTML = embed;
  }
  
  embedDoc('project-intro');
  ```
  ```python
  import s1vo
  
  async def embed_doc(doc_id):
      embed = s1vo.embed(doc_id, theme='light', api_key='YOUR_API_KEY')
      return embed.html
  
  embed_doc('project-intro')
  ```
</CodeGroup>
